# Primary sources and chronology

**10 August 2022 — Siemens, named C.E. Schneckenflügel case.** The [Opcenter APS case](https://blogs.sw.siemens.com/opcenter/case-study-c-e-schneckenflugel-increases-sales-100-by-accelerating-customer-delivery-time/) describes advanced detailed production planning with implementation partner A+B Solutions. It supports the relevance of scheduling workflows. Its reported business outcomes belong to that customer and vendor report; it is not evidence of language-model accuracy or P07 outcomes.

**3 June 2026 — Microsoft, Sight Machine / OptiMind.** The [customer story](https://www.microsoft.com/en/customers/story/26648-sight-machine-microsoft-foundry) describes natural-language input leading to mathematical formulation and generated MIP code for an unnamed beverage manufacturer/bottler through Microsoft Foundry. The supplier-reported benefits refer to different measures, including planning effort, non-value-added time and capacity, without a disclosed evaluation population or a common denominator. P07 does not copy those ROI claims. It never executes generated optimization code; its fixed typed allowlist and original enumerator are a smaller design, not a reconstruction of the vendor's private architecture.

**Primary scheduling reference — Google OR-Tools.** The [job-shop guide](https://developers.google.com/optimization/scheduling/job_shop) explains job precedence, fixed machine assignment, machine exclusivity, non-preemptive work and makespan minimization. It informs the declared mathematical slice; P07 does not install or use OR-Tools, and the guide does not validate our implementation. Executed tests and an independent verifier provide the project's own correctness evidence.

All requirements, operations, requests, deadlines and calendars in this project are original fictional fixtures. Customer-story results are contextual attribution only. There is no claimed factory deployment, throughput improvement, vendor accuracy, private data access or enterprise integration.
